¿Qué detecta VulnShield?

Amenazas

Estos son los tipos de hallazgos que el motor actual identifica mediante fuzzing y análisis de respuesta.

SQL Injection en URL

Prueba múltiples payloads SQL en parámetros GET y marca hallazgos cuando detecta firmas de error en la respuesta.

Severidad alta

XSS Reflejado en URL

Evalúa payloads XSS y detecta reflejo exacto, patrones de script o funciones JavaScript sospechosas en la respuesta.

Severidad media

SQLi en Formularios (POST)

Encuentra formularios automáticamente, envía payloads en campos input y valida si aparecen errores de base de datos.

Severidad alta

XSS en Formularios (POST)

Envía payloads XSS en formularios y reporta el hallazgo cuando el payload regresa reflejado en el contenido de respuesta.

Severidad media

Errores SQL Expuestos

Reconoce mensajes de error de motores como MySQL, PostgreSQL, Oracle, SQLite y ODBC para evidenciar exposición de backend.

Evidencia técnica

Reputación de URL (VirusTotal)

Si existe VIRUSTOTAL_API_KEY, consulta detecciones malicious/suspicious y agrega el resultado al reporte del escaneo.

¿Cómo funciona?

Capacidades del escáner

El flujo actual está enfocado en pruebas DAST de SQLi/XSS y trazabilidad de resultados en dashboard y reportes.

Fuzzing con diccionarios de payloads

Ejecuta múltiples cargas para SQL Injection y XSS, tanto en URL como en formularios detectados.

Análisis GET y POST automatizado

Busca etiquetas form, prepara datos falsos por campo y envía solicitudes para validar comportamientos inseguros.

Detección por evidencia en respuesta

Clasifica hallazgos por errores SQL, patrones XSS y reflejo de payload, asignando severidades Alta o Media.

Registro y visualización de resultados

Guarda hallazgos en base de datos y los muestra en dashboard, historial de escaneos y vista de reporte.
